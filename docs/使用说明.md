# PortViewer 使用说明

## 启动

双击 `PortViewer.exe` 即可启动。程序平时以普通用户权限运行，不会在启动时请求管理员权限。

首次打开后会立即扫描，并默认每 3 秒刷新一次。取消勾选“每 3 秒自动刷新”可暂停自动刷新；点击“立即刷新”可随时重新读取。

## 查看与搜索

- “监听端口”视图展示 TCP 监听端口和全部 UDP 绑定。
- 选择“全部 TCP 连接”后，还会展示 TCP 已建立、等待关闭等连接状态。
- 搜索框支持端口、PID、进程名、Windows 服务名、协议、IP 地址和连接状态。
- 点击表头可按该列排序；双击一行可查看完整进程路径和该进程的端口清单。

部分系统进程的名称、路径或服务信息可能因 Windows 权限保护而显示为“无法访问”，但不影响可读取的端口、协议和 PID 信息。

## 关闭占用进程

1. 选择目标端口所在行。
2. 点击“关闭占用进程”。
3. 仔细核对确认框中的 PID、进程、服务及全部受影响端口。
4. 确认后，PortViewer 会再次检查端口归属和进程启动时间，然后强制结束目标进程。
5. 如果普通权限不足，Windows 会显示 UAC 确认框；取消 UAC 不会执行任何操作。

重要：Windows 无法让外部工具通用地“只关闭另一个进程中的一个端口”。此操作实际会结束整个进程，其全部端口、连接和未保存数据都会受到影响。Windows 服务进程还可能被服务管理器自动重启。

PortViewer 会拒绝结束 PID 0、PID 4、PortViewer 自身和 Windows 关键进程；如果无法安全确认目标身份，也会取消操作。

## 排查文件或文件夹占用

1. 点击窗口顶部的“文件占用”，粘贴本机完整路径，或点击“选文件”“选文件夹”。
2. 点击“查找占用进程”。结果会按进程列出名称、PID、服务、命中路径和端口记录。文件夹查询包括文件夹自身以及其内部文件，不会逐个遍历目录。
3. 选择进程并点击“查看进程详情”。优先回到对应程序正常关闭文件，保存未完成的工作。
4. 如果仍需处理，点击“强制结束所选进程”，核对再次扫描的路径、进程、服务和端口影响范围，确认后才会结束整个进程。程序会再扫描一次；请回到文件管理器重试原操作。
5. 如果权限不足，可点击“管理员模式重新扫描”，在新窗口重新核对目标后操作。取消 UAC 不会结束进程。

扫描超过 30 秒会自动停止。扫描不完整或没有结果，并不能证明目标没有被占用；受保护进程、系统驱动及远程共享可能无法识别。显示某进程打开了路径，也不能单独证明它阻止了删除或移动。PortViewer 不直接关闭单个句柄，不删除或移动文件。文件页面按需扫描；切回端口页面时恢复原有自动刷新设置。

## 系统要求与卸载

- 支持 Windows x64。
- 发布版为自包含单文件，无需预装 .NET。
- 无安装程序，不写入开机启动项。退出后删除整个发布文件夹即可移除程序。
- EXE 未进行商业代码签名，首次运行时 Windows SmartScreen 可能显示提示。可使用同目录的 `SHA256SUMS.txt` 核对文件完整性。
